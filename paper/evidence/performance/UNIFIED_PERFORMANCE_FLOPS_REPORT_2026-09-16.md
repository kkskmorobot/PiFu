# Plain 与 LGLA v1 统一性能及 FLOPs 报告

## 结论

在同一台 RTX 5080 上，使用 FP32、输入 1×3×640×640、batch=1、相同预热和重复次数后，LGLA v1 相对 Plain 只增加 33,410 个参数（+0.2303%）和 0.1051 GFLOPs（+0.1764%）。直接前向平均耗时增加 0.1939 ms（+3.5446%），Ultralytics 完整预测管线平均耗时增加 0.3202 ms（+5.1434%）。因此可以写成“计算量增幅很小、实测速度略慢”，不宜写成完全无开销。

## 统一条件

- GPU：NVIDIA GeForce RTX 5080。
- PyTorch：2.8.0+cu129；CUDA 12.9。
- 精度：FP32；batch=1；输入 640×640。
- 直接前向：20 次预热、100 次重复，CUDA event 包围 `model(x)`，不含预处理、后处理和主机传输。
- 完整预测管线：5 次预热、30 次重复，相同内存 PIL 图像 `ISIC_0024307.jpg`，wall-clock 包围 `wrapper.predict` 并在结束同步 CUDA。
- FLOPs：Ultralytics THOP 口径，乘加按 2 次浮点运算；另保存 PyTorch Profiler 值作为交叉检查。

## 结果

| 指标 | Plain Run22 | LGLA LGX | LGLA 相对 Plain |
|---|---:|---:|---:|
| 参数量 | 14,507,338 | 14,540,748 | +33,410（+0.2303%） |
| THOP GFLOPs | 59.5741 | 59.6791 | +0.1051（+0.1764%） |
| PyTorch Profiler GFLOPs | 59.0201 | 59.0489 | +0.0287 |
| 直接前向平均耗时 | 5.4703 ms | 5.6642 ms | +0.1939 ms（+3.5446%） |
| 直接前向 P95 | 10.1642 ms | 7.7342 ms | 单次测量波动，不作为优劣结论 |
| 直接前向平均吞吐 | 182.80 FPS | 176.55 FPS | -6.26 FPS |
| 完整管线平均耗时 | 6.2254 ms | 6.5456 ms | +0.3202 ms（+5.1434%） |
| 完整管线 P95 | 9.9161 ms | 7.5844 ms | 单次测量波动，不作为优劣结论 |
| 完整管线平均吞吐 | 160.63 FPS | 152.77 FPS | -7.86 FPS |
| 峰值 allocated 显存 | 194.449 MiB | 195.579 MiB | +1.130 MiB |

## 使用限制

这些数据是单机工程基准，不是跨硬件标准成绩。截图中的 `request_total_ms`、首次模型加载时间、100 张批量总时长和本报告的直接前向时间边界不同，不能混表比较。FLOPs 已成功计算，因此本项不再留空；原始逐次统计、权重哈希和完整协议见 `unified_performance_results.json`。
