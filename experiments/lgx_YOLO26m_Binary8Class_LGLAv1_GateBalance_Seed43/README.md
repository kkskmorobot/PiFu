# lgx pre-training container

This directory is reserved for the single preregistered gate-balanced LGLA v1
revision at seed 43. Formal output will be created only by the user's manual
PyCharm run of `tools/lgx/train_lgx_from_pycharm.py`.

At preparation time, `results/lgx_yolo26m_lgla_v1_gate_balance_seed43` must not
exist. Test, external, and PAD-UFES-20 data are forbidden during lgx development.
