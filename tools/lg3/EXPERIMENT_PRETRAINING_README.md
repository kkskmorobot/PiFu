# lg3 pre-training container

This directory is reserved for the exact successful lgx gate-balanced LGLA v1
replication at seed 44. Formal output will be created only by the user's manual
PyCharm run of `tools/lg3/train_lg3_from_pycharm.py`.

At preparation time, `results/lg3_yolo26m_lgla_v1_gate_balance_seed44` must not
exist. Test, external, and PAD-UFES-20 data are forbidden during lg3 development.
